# AGENTS.md

Instructions for AI agents working in this repository.

## About this repo

Personal research workspace on climate-fiscal economics, sovereign risk and related modelling. It holds papers, a Quarto website, a scripting engine and shared templates. See `README.md` for the folder layout. Folders with their own `README.md` have local conventions, so read that first.

## General rules

- Make only the changes requested. Don't reorganise, rename or delete files unless asked.
- Read a file before editing it, and match the style and formatting of the surrounding content.
- Ask before taking any action that is hard to reverse or visible to others.
- Don't modify source papers, data or reference material unless the task requires it.
- Don't commit secrets, credentials or personal data.
- Don't invent citations, figures or results. Mark anything uncertain or unverified.

## Git

- Work on the branch you were assigned. Don't push to other branches.
- Write clear, descriptive commit messages.
- Don't open pull requests unless asked.

## Writing and research

- Keep a precise, academic tone. Be concise.
- State assumptions and sources explicitly.
- Keep terminology and numbers consistent with the existing papers.

## Website and scripts

- The Quarto site source is in `B Research and Website/7.Website`, and the automation engine is in `8.Scripts`. Check their READMEs before changing them.
- Don't commit generated output unless the repo already tracks it.
