# Reference

Data the scripts read or write. Nothing here is executable.

- `_PaperIndex.csv` — rebuilt by `Steps\Reorganize-Papers.ps1` on every run: one row per paper folder, what was found and where it went.
- `_PaperFolderLayout.md` — the slot convention every paper folder follows.
The status sheet, `PaperTracker.xlsx`, is not here: it lives in `0.Overview`
alongside the other finished material, so there is only ever one copy.
- `_CoreFiles.txt` — hints Reorganize-Papers reads when it cannot tell which file is the master.
