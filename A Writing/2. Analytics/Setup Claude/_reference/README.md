# _reference

Things worth copying rather than reinventing.

What belongs here:

- Document templates — memo, brief, terms of reference, slide skeleton
- Style guides and house formatting rules
- Boilerplate — standard disclaimers, methodology notes, data citations
- Past work I was happy with, kept as a model for tone and structure

What does not belong here: source material for a live project (that's `inputs\`),
or anything still being written (that's `working\`).
