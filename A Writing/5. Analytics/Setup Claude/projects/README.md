# projects

One folder per project. Each follows the same three-part shape:

- `inputs\`  — source material, unmodified. Read-only by convention.
- `working\` — drafts, scratch, analysis in progress. Expected to be messy.
- `outputs\` — the finished deliverable.

`project-a\` is the skeleton. Copy it, rename it to something meaningful, and fill
in its README before starting.
