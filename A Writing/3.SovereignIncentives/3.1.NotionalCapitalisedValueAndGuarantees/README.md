# 3.1 Notional Capitalised Value and Guarantees

Status: no draft yet. Abstract in `research.qmd`.

Sovereign incentive framework: countries receive a notional climate balance
linked to carbon stocks and long-run emissions performance, translated into
guarantee-based support that is gradually used up by business-as-usual
emissions.

Supersedes the earlier working title "Guarantee-Based International Incentives
for the Delivery of Strong NDCs".

Top paper in the sovereign incentives cluster. Related: 3.2 Sustainability-Linked
Lending, 3.3 Climate Investment Trust.
