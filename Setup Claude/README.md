# Claude Workspace

A shared folder Claude and I both work in. The structure exists so that neither
of us has to guess where something lives.

```
_admin\        who I am, how I write, standing rules — read first
_reference\    templates, style guides, boilerplate, past work worth copying
_inbox\        raw drop zone: PDFs, screenshots, transcripts, exports
projects\      one folder per project: inputs\ working\ outputs\
outputs\       finished deliverables that span more than one project
_archive\      done, but not deleted
```

Underscore-prefixed folders sort to the top. That's the only reason for the underscore.

**Starting a new project:** copy the `project-a\` skeleton, rename it, and note
in its README what the project is for and what "done" looks like.
